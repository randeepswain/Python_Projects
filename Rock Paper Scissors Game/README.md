# 🪨Rock 📄Paper ✂️Scissors 

A simple Python project that lets the player play Rock Paper Scissors against the computer.

## ✨ Features

* 🪨 Allows the player to choose **Rock, Paper, or Scissors**
* 🤖 Computer randomly selects an option
* 🏆 Determines the winner based on the choices
* 🤝 Handles **tie games**
* 🔄 Displays both the player's and computer's choices

## 🛠️ Technologies Used

* 🐍 Python
* 🎲 `random` module
